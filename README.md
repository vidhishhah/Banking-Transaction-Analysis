# Banking Transaction Analysis using MySQL

## Project Overview
This project analyzes over 1 million banking transactions using MySQL to identify transaction patterns, account activity, transaction values, and time-based trends.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Analysis Covered

* Transaction modes and types
* Transaction amounts and high-value transactions
* Account activity
* Monthly and yearly trends
* Day-of-week transaction patterns
* SQL concepts including **CASE, CTEs, subqueries, and JOINs**

## Key Insights

* Card Out had the highest transaction volume with 215,909 transactions.
* NGN to USD was the most common transaction type.
* Total transaction value exceeded **14.43 trillion.
* January recorded the highest transaction volume.
* Card Out had the highest total transaction value at approximately 297.06 billion.
* Transaction activity was fairly consistent across the days of the week.

## Dataset

SFinDSet financial transaction dataset containing over **1 million synthetic banking transactions.
